# Proyecto Pikachus

Web estática construida con HTML, CSS y módulos JavaScript nativos, sin dependencias ni paso de compilación.

## Ejecutar en local

1. Abre la carpeta `ProyectoPikachus` en Visual Studio Code.
2. Instala o habilita la extensión Live Server si aún no está disponible.
3. Abre `index.html` y selecciona **Open with Live Server**.
4. Comprueba que se muestra el encabezado de PokéCards y el estado inicial de la galería.

Sirve la página mediante HTTP local en vez de abrir el archivo directamente: los módulos JavaScript del navegador necesitan un origen local.
